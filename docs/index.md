# parser3 — документация

Парсер контактов ЛПР с корпоративных сайтов: обходит сайты, извлекает ФИО,
должности, телефоны, email, соцсети и реквизиты, раскладывает по ролям и отдаёт
Excel.

## Разделы

- **[Руководство пользователя](user-guide.md)** — как загрузить сайты, режимы
  парсинга, что на выходе, как читать результат и статусы.
- **[Руководство разработчика](developer-guide.md)** — деплой, порты, nginx,
  Basic Auth, переменные окружения, справочник API и сборка.

## Коротко о структуре

- `parser3` (prod) и `parser3-dev` (dev) — **один и тот же код**, разные деплои
  (`/parser3` на портах 8767/8768, `/parser3-dev` на 8769/8770).
- Извлечение полностью классическое — **ИИ/LLM внутри нет**.
- `parser2` (с ИИ) — отдельная кодовая база вне этого репозитория, здесь не
  документируется.
